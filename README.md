## Установка и запуск
#### ТРЕБОВАНИЯ:
*go 1.24 или новее*

#### Установка
```shell
git clone https://github.com/igikawa/awesomer.git
cd awesomer
go mod tidy
go build -o awesomer cmd/project/main.go
chmod +x ./awesomer
./awesomer
```

## Архитектура проекта

- `cmd` 
- - `project` - Запуск 
- `internal` - Основные пакеты
- - `config` - Загрузка конфигурации из `.env`
- - `daemon` - Фоновый демон для мониторинга и ограничивания процессов
- - - `config` - Конфигурация демона
- - `processes`- Управление процессами (чтение /proc и `syscall`)
- - - `parser` - Парсинг из дирректории /proc
- - `tui` - Описание и запуск консольного интерфейса
- `pkg` - Общие пакеты
- - `cgroups` - Интерфейс для работы с cgroups
- - `logger` - Логгер (пишет в awesome.log)

## Сортировки и сочетания клавиш
Утилита поддерживает сортировку процессов по разным параметрам процесса.

#### Сортировки

- `PID`: по идентификатору(в порядке возрастания) процессы сортируются
**по умолчанию** или если нажать клавишу `p`
- `Name`: по имени(в алфавитном порядке) процессы сортируются если нажать
клавишу `n`
- `CPU`: по нагрузке на процессор(в порядке убывания %) процессы сортируются
если нажать клавишу `c`
- `Mem`: по нагрузке на ОЗУ(в порядке убывания %) процессы сортируются
если нажать клавишу `m`
- `Threads`: по количеству используемых потоков(в порядке убывания) процессы
сортируются если нажать клавишу `t`

#### Управление конкретным процессом

- нажать `s` для временной остановки выделенного процесса
- нажать `r` для продолжения выделенного процесса если он был остановлен
- нажать `k` для принудительного завершения выделенного процесса
- нажать `d` для принудительного завершения ДЕРЕВА процесса, где корень - выделенный процесс

*для выделения процесса использовать стрелочки вверх и вниз на клавиатуре*

#### Вывод информации на боковую панель

Нажатие клавиши enter выводит подробную информацию о процессе на боковую панель. Это могут быть команда запуска, 
nice, username. 

`h` - для больших данных по типу дерева процессов,
сетей и файловых дескрипторов.

#### Выход из программы
Для выхода используется сочетание клавиш `Ctrl+c` или нажатие клавиши `q`

## Файл конфигурации

### Частота обновления списка процессов
- `TICK` - определяет частоту обновления списка процессов в секундах.
Если равна 0 список будет статичным (не будет обновляться в реальном времени).
Если не задан, по у молчанию будет равен 1 секунде.

### Логирование
- `LOG_PATH` - полный путь к файлу с логами
- `DAEMON_LOG_PATH` - полный путь к файлу с логами демона

## Демон

Фоновый демон запускается вместе с утилитой и настраивается через конфигурационный файл `.env`. Если процесс превышает
заданный порог использвания ресурсов машины ему дается замечание. После 3 замечаний процесс и его подпроцессы попадают
в контрольную группу, где им задается ограничение на использование ресурсов компьютера.

### Пример конфигурации

```dotenv
DAEMON=true         # включение/выключение демона
DAEMON_TICK=5       # частота проверки процессов демоном в сукундах
DAEMON_CPU_LIMIT=85 # порог использования ЦП после которого процесс получает "замечание"
DAEMON_RAM_LIMIT=60 # порог использования ОЗУ(в процентах) после которого процесс получает "замечание"
DAEMON_CPU_QUOTA=20 # ограничение на использование процессора для процессов попавших в контрольную группу
DAEMON_RAM_QUOTA=8G # ограничение на использование ОЗУ для процессов попавших в контрольную группу
```
